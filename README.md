- 🤖 **HADES** — https://hades-client.onrender.com
- 🕉️ **Low-Resource Sanskrit–English Neural Machine Translation** *(TensorFlow, Keras, SentencePiece)*
  End-to-end NLP pipeline with a 6-layer Transformer and a BiLSTM encoder-decoder with Bahdanau attention. Uses beam search, gradient clipping, warmup scheduling, masked loss, SentencePiece (7k vocab), data augmentation, and BLEU / METEOR / BERTScore evaluation.
- 🧪 **Cognitive Fatigue Detection System** *(Python, Scikit-learn, NumPy, Pandas, Joblib)*
  Automated ML pipeline predicting cognitive fatigue from behavioral time-series signals. Per-participant rolling baseline normalization cut inter-user variance by 60%, and low / medium / high risk classification improved precision by 72% with 25–30% lower MAE than rule-based baselines.
